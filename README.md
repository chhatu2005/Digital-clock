# Digital Clock

## Day 4 Task - Veda Technology

A simple responsive digital clock built using HTML, CSS, and JavaScript.

## Features

- Displays the current time
- Shows hours, minutes, and seconds
- Automatically updates every second
- Uses 12-hour time format
- Adds leading zeros to single-digit values
- Responsive design for mobile devices

## Technologies Used

- HTML5
- CSS3
- JavaScript
